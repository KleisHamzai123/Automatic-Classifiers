# MNIST Classification with SVM, KNN, and Random Forest

This repository contains Python implementations of three popular machine learning algorithms—Support Vector Machines (SVM), k-Nearest Neighbors (KNN), and Random Forest—applied to the MNIST dataset. The MNIST dataset consists of handwritten digit images, which serve as a standard benchmark for evaluating classification algorithms.
